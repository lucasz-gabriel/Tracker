# Tracker

Sistema web de controle financeiro pessoal: registra entradas, saídas e
assinaturas, mostra o saldo atual e prevê se o mês fecha com superávit
ou déficit.

## Status

Em desenvolvimento. Hoje: estrutura do front-end.

## Tecnologias

- Front-end: HTML, CSS e JavaScript
- Back-end (planejado): Python com FastAPI
- Banco de dados (planejado): SQLite com SQLAlchemy

## Funcionalidades planejadas

- [ ] Cards de resumo (saldo, entradas, saídas, previsão)
- [ ] Lançamento de entradas e saídas
- [ ] Gráfico de rosca (entradas vs. saídas)
- [ ] Tabela de transações
- [ ] Assinaturas recorrentes
- [ ] Persistência dos dados em banco
